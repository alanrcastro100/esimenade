## Stack Tecnológico

- Front-end: React + TypeScript (Vite), estilizado com Tailwind CSS para garantir interface limpa. (Execução local).
- Back-end API: Python (FastAPI). Centraliza rotas de controle de
acesso, upload de PDF e listagem/resolução. (Execução local).
- Banco de Dados: SQLite. (Execução local)
